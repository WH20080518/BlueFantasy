# 演示脚本（60–90 秒）

> 版本：v1 · 2026-11-11
> 用途：录屏演示 / 现场答辩开场。**先写脚本，再删 beat。**
> 原则：一个动作说一句话；不说话的时候就让画面动。

## 0. 两个版本

| 版本 | 时长 | 用途 |
|---|---|---|
| A · 完整版 | 90 s | 提交视频、答辩开场 |
| B · 极简版 | 45 s | 社交媒体、群里转发 |

两版共用素材，B 版删掉 beat 4 和 beat 6 的口播。

## 1. A 版分镜（90 秒）

| 时间 | 画面 | 操作 | 旁白（中） |
|---|---|---|---|
| 0–8 s | 黑场 → 船体剪影淡入，缓慢自转 | 无 | 「都说中国古船不用一根钉。」 |
| 8–16 s | 字幕浮出「真的吗？」 | 轻微下滚 | 「这句话很浪漫。但它只说对了一半。」 |
| 16–30 s | 镜头推近，榫头与卯眼分开 | 点击榫头 | 「榫头插进卯眼，木头靠形状互相咬住——这是真的。」 |
| 30–44 s | 接缝剖面分层出现 | 依次点「榫卯 / 铁钉 / 捻缝」 | 「但船要下水。所以还要钉，还要用桐油灰拌麻丝把缝捻死。」 |
| 44–52 s | 船体剖切，三道隔舱板亮起 | 点击第 2 道隔舱板 | 「船身被隔成一个个互不相通的舱。」 |
| 52–72 s | 漏水实验：单舱进水，船倾斜后稳住 | 切「有隔舱」→「无隔舱」 | 「一个舱破了，船还浮着。抽掉隔舱板，同样的破口，水就一路漫过去。」 |
| 72–82 s | 回到整船，中英词条浮出 | 点 `中 / EN` | 「英文里没有『榫卯』这个词。最接近的说法是 mortise-and-tenon joint。」 |
| 82–90 s | 收束字幕 | 静止 | 「木头咬住木头，钉子咬住木头，语言咬住语言。」 |

**字幕**：中文口播全程配英文字幕（简短版，不逐字译）。

## 2. B 版分镜（45 秒）

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0–6 s | 船体剪影 | 「都说中国古船不用一根钉。」 |
| 6–18 s | 榫卯爆炸 → 接缝剖面 | 「榫卯是真的，钉和捻缝也是真的。」 |
| 18–34 s | 漏水实验切换 | 「一个舱进水，船不沉。这就是水密隔舱。」 |
| 34–45 s | 术语对照 → 收束 | 「翻译也是一次榫合。」 |

## 3. 录屏执行清单

- [ ] 分辨率 1920×1080，浏览器缩放 100%，窗口无书签栏
- [ ] 关掉所有通知；关闭鼠标指针高亮（除非讲解需要）
- [ ] 用 `?no3d=0` 正常模式录；另录一条 `?no3d=1` 作为备份片段
- [ ] 滚动速度：每屏 1.5–2 秒，漏水实验停留 3 秒
- [ ] 录音单独录，不要用系统内录 + 现场讲话混音
- [ ] 导出 H.264，码率 ≥ 8 Mbps；同时导出一版 1080×1920 竖版用于手机

## 4. 现场答辩备用动作

如果现场网络或机器撑不住 WebGL：

1. 直接打开 `?no3d=1`，画面是 SVG，文案完整。
2. 口播不变，漏水实验改用手动切图（两张 SVG）。
3. 提前把 90 秒视频存在本地，随时可放。
