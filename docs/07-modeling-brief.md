# 建模 Brief：《榫合》船体与榫卯节点

> 用途：交给 3D / 建模同学执行。目标不是“造一艘完整的船”，而是做一套能在网页里讲清结构的低模资产。
>
> 方向假设：B 赛道交互式网页《榫合 / 一榫一钉》，用一艘中国古船的剖切与节点，纠正“古船不用一根钉”的误解。

---

## 0. 一页版（可直接转发）

**要做的东西**

1. 一艘古船的**剖切低模**：外壳 + 3 道隔舱板 + 龙骨，能看到内部
2. 一个**爆炸节点**：榫头、卯眼、木钉/铁钉、捻缝，单独放大
3. 一段**船壳板接缝**：带钉孔与捻缝，用于“补缝”交互

**不要做**

- 全船高模、完整内舱、桅杆索具、人物
- 真实海水、流体模拟、物理引擎
- 复杂 PBR 贴图、4K 纹理

**预算**

- 总三角面 ≤ 35,000
- GLB ≤ 5 MB（Draco 压缩后）
- 纹理 ≤ 2 张 1024，或不用贴图、只用顶点色/AO
- Draw call ≤ 20

**交付**

- Rhino `.3dm` 源文件
- `.obj` 或 `.fbx`（分件、命名正确）
- `.glb`（Blender 导出，Draco）
- 零件命名清单 + 三角面统计 + 3 张截图（正视 / 剖切 / 节点）

**时间**

- 11-13 前：船体 blockout 确认比例
- 11-15 前：剖切 + 节点初版
- 11-16 前：GLB 定稿，交给前端

## 1. 叙事与 3D 的角色

网页的核心不是“展示一艘船”，而是回答三个问题：

1. 中国古船是不是“纯榫卯、不用钉”？
2. 榫卯、钉接、捻缝、水密隔舱各自解决什么问题？
3. 这些结构为什么能让船穿过风浪？

3D 只承担“证据”的角色：剖开、拆开、放大。**不要用 3D 做装饰性转场。**

### 建议的 5–7 个 beat

| # | Beat | 3D 动作 |
|---|---|---|
| 1 | 一个流行误解 | 整船轮廓，外壳半透明 |
| 2 | 榫头与卯眼 | 镜头推到节点，爆炸 |
| 3 | 钉与缝 | 铁钉、木钉、捻缝分层出现 |
| 4 | 水密隔舱 | 剖切，露出 3 道隔舱板 |
| 5 | 漏水实验 | 一个舱进水，船仍浮 |
| 6 | 术语出海 | 节点旁弹出多语种词条 |
| 7 | 今天 | 回到整船，收束 |

## 2. 资产清单与命名

所有对象名用英文小写 + 下划线，前端按名字查找，不要用中文名或默认 `Object01`。

| 资产 | 节点名 | 三角面预算 | 说明 |
|---|---|---:|---|
| 船体外壳 | `ship_hull` | 9,000 | 只做可见外壳，厚度 60–100 mm |
| 甲板 | `ship_deck` | 2,500 | 可省略细节 |
| 龙骨 | `keel` | 1,500 | 贯穿首尾 |
| 艏柱 | `stem` | 800 | 船首 |
| 艉柱 | `sternpost` | 800 | 船尾 |
| 隔舱板 01 | `bulkhead_01` | 1,200 | 带人孔/水孔 |
| 隔舱板 02 | `bulkhead_02` | 1,200 | 同上 |
| 隔舱板 03 | `bulkhead_03` | 1,200 | 同上 |
| 船壳板段 | `plank_section` | 2,000 | 用于补缝交互 |
| 榫头 | `joint_tenon` | 2,000 | 单独放大 |
| 卯眼构件 | `joint_mortise` | 2,000 | 与榫头配套 |

## 3. 单位、坐标、比例

- **Rhino 建模单位**：毫米（mm）
- **导出单位**：米（m），缩放 `0.001`
- **场景比例**：1 Three.js 单位 = 1 米
- **船体参考长度**：25–30 m（视觉比例即可，不必对应某艘具体沉船）
- **原点**：船中、龙骨顶部、中线交点
- **轴向**：
  - `+X` 指向船首
  - `+Y` 指向左舷
  - `+Z` 向上（Rhino）
  - glTF 为 Y-up，走 Blender 导出会自动转换
- **每个零件的 pivot**：放在自身几何中心或装配基准点，爆炸动画按 pivot 移动

> 不要用“看起来差不多”的比例。前端会把零件按米制摆放，比例错了爆炸图会散。

## 4. Rhino 建模规范

### 4.1 图层

```
SHIP_HULL        船体外壳、甲板
SHIP_STRUCT      龙骨、艏柱、艉柱、隔舱板
JOINT            榫头、卯眼
FASTENER         木钉、铁钉
CAULKING         捻缝
REF              参考线、参考图（导出前关闭）
```

### 4.2 建模顺序

1. 画船体中线、甲板边线、龙骨线
2. 建外壳曲面，加厚 60–100 mm
3. 放 3 道隔舱板，切出人孔/水孔
4. 建龙骨、艏柱、艉柱
5. 单独建榫头/卯眼节点（可脱离船体，放大 2–3 倍做展示）
6. 建船壳板段、钉、捻缝
7. 按图层分色，不贴图

### 4.3 网格转换

- `Mesh` 角度公差：**5–10°**，不要 1°
- 船体曲面可用 `QuadRemesh`，目标 8,000–10,000 面
- 开放边用 `ShrinkWrap` 封闭，避免前端看到破面
- 隐藏内部面、重复面、背面
- 剖切面要封口，不要留空壳

### 4.4 导出

- 优先：`OBJ`（分件、保留名称）或 `FBX`
- 单位选米；如果 Rhino 只能导毫米，Blender 里统一缩放 `0.001`
- 每个零件独立对象，不要合并成一个 mesh
- 材质只保留基础色，导出时不带贴图

> Rhino 8 若支持 glTF 导出可以试，但仍建议走 Blender 过一遍减面、UV、AO，否则网页端容易翻车。

## 5. Blender 后处理

### 5.1 导入与清理

1. 导入 OBJ/FBX
2. 检查尺度：船长约 25–30 个单位
3. `Apply All Transforms`
4. `Merge by Distance`、`Recalculate Normals`
5. 删除松散点、隐藏面、重复面
6. 需要时 `Decimate`，但不要破坏榫卯的硬边

### 5.2 法线与着色

- `Shade Smooth` + `Auto Smooth` 30°
- 硬边处加 `Weighted Normal`
- 不要加 Subdivision

### 5.3 UV 与烘焙

- `Smart UV Project`，margin 0.02
- 一张 1024 或 2048 图集
- 烘 `AO` 到贴图；如嫌麻烦，直接用顶点色/纯色材质
- 不做 metallic/roughness 贴图，前端统一给材质

### 5.4 材质

- 每个零件一个基础色，颜色由前端覆盖
- 建议导出时保留 `Base Color`，不要依赖 Blender 节点
- 木色、深褐、铁灰、灰白四组即可

### 5.5 导出 GLB

- `File → Export → glTF 2.0`
- 格式：`glTF Binary (.glb)`
- `+Y Up`
- 应用修改器
- `Draco` 压缩，level 6
- 只导出选中对象
- 检查：三角面、文件大小、节点名是否保留

### 5.6 验证

```bash
npx gltf-transform inspect public/models/ship.glb
```

重点看：

- `triangles` ≤ 35,000
- `file size` ≤ 5 MB
- 节点名与清单一致
- 没有多余相机、灯光、空节点

## 6. Three.js 集成约定

### 6.1 文件位置

```
public/models/ship.glb
public/models/ship-parts.json   # 爆炸位置与说明
```

### 6.2 加载

- `GLTFLoader` + `DRACOLoader`
- `renderer.outputColorSpace = THREE.SRGBColorSpace`
- 像素比上限：`Math.min(devicePixelRatio, 2)`
- 页面隐藏时暂停渲染

### 6.3 节点查找

前端只按约定名查找：

```js
const part = scene.getObjectByName('joint_tenon')
```

缺节点时不要静默失败，控制台报出缺失名。

### 6.4 爆炸动画

不要用物理引擎。每个零件在 JSON 里存两组位置：

```json
{
  "joint_tenon": {
    "assembled": [0, 0.4, 0],
    "exploded": [0, 1.8, 1.2],
    "label": { "zh": "榫头", "en": "tenon" }
  }
}
```

动画：

- 位置 lerp，缓动 `cubic-bezier(.22, 1, .36, 1)`
- 时长 600–900 ms
- 零件错峰 40–60 ms
- `prefers-reduced-motion` 时直接切换，不做位移动画

### 6.5 交互状态

| 状态 | 表现 |
|---|---|
| idle | 基础材质，轻微呼吸光 |
| hover | 边缘高亮/自发光 + 名称提示 |
| selected | 相机聚焦，其他零件降透明度 |
| assembled | 零件在装配位 |
| exploded | 零件在爆炸位 |
| flooded | 水面上升，船体倾斜 |
| repaired | 捻缝补齐，水停止渗入 |

### 6.6 漏水实验

- 不需要流体模拟
- 用半透明 `water_plane` 上升 + 船体轻微倾斜
- 隔舱板开启时，进水限制在单舱；关闭时整船下沉
- 动画 2–3 秒，可重复播放

### 6.7 补缝交互

- 点击 `plank_section` 上的接缝
- 用户按顺序点“榫卯 / 铁钉 / 捻缝”
- 选错显示渗水粒子（CSS/SVG 即可），选对补齐
- 移动端用点击，不做拖拽

### 6.8 可访问性

- 3D 区旁边提供“零件列表”按钮，键盘可切换
- `aria-live` 播报当前选中零件
- 不用颜色作为唯一状态提示
- 提供“关闭 3D / 查看图解”开关

---

## 7. 镜头与灯光

- 主视角：3/4 侧前，略高，能看到剖切面
- 镜头焦距：35–50mm 等效，不要广角畸变
- 灯光：Hemisphere + 一盏方向光 + 一盏轮廓光
- 不要依赖 HDR 环境贴图，避免加载失败
- 地面接触阴影用简单平面 + 径向渐变即可
- 聚焦节点时，相机 600ms 缓动，返回时同路径

## 10. 参考与事实核查

- 泉州湾宋代海船（福建泉州）

- 华光礁I号（西沙）

**注意**：

- 不同沉船的榫卯、钉接、捻缝做法不完全相同，页面文案用“常见做法”而不是“所有古船都这样”
- 不要声称“完全不用钉”
- 不要直接使用博物馆模型或他人 3D 资产，除非有明确授权
- 尺寸与构件比例以“视觉可信”为准，不要伪造精确考古数据

## 13. 一句话总结

**做“结构证据”，不做“整船模型”。** 一个讲得清的节点，胜过一艘面数很高的船。
