## 3. 需要改写的表述

| 原文案 | 问题 | 改为 |
|---|---|---|
| 「中国古船不用一根钉」 | 作为结论是错的；作为流行说法可以使用 | 保留为**被质疑**的说法，页面明确标注「这是一句流行说法」 |
| 「水密隔舱领先西方数百年」 | 数字争议大，且不属本作品论证重点 | 删；改为「隔舱板把船分成互不相通的舱室」 |
| 「世界上最早的…」 | 无来源 | 一律删 |
| 「考古精确复原」 | 我们的模型是示意 | 统一写「结构示意」 |
| 「13 个舱」（模型展示 3 个） | 数量不一致，易被追问 | 展示处写「此处示意 3 道隔舱板」，来源区另写「12 道隔舱板、13 舱」 |
| 「古船不用钉，全靠榫卯」 | 与 F07 冲突（有钉、有艌料） | 已改为「榫卯定位、钉加固、捻缝水密」 |
| 「直角同口」 | 查无出处（见 F06） | 若需要一个冷门细节，改用「保寿孔 · 七星伴月」（F06b） |
| 「鱼鳞式搭接」 | 属法石古船，不是后渚船（见 F05b） | 后渚船写「平接与搭接混用」 |

## 4. 明确不使用的说法

- ❌ 「中国古船全靠榫卯，不用钉」——与造船史事实冲突。
- ❌ 「榫卯是中国独有」——日本、欧洲均有同类节点，只是形制不同。
- ❌ 「mortise-and-tenon 是榫卯的唯一正确译法」——术语表已改为「最接近的英文表达」。
- ❌ 「直角同口」——查无机构来源，S2 为「斜直角法榫合」。
- ❌ 「后渚船用鱼鳞式搭接」——该说法属法石古船。
- ❌ 任何未经核对的船长、吃水、排水量数字。
