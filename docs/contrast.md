# 对比度实测（C · 视觉）

测量时间：2026-11-11 · 对象：当前工作区版本（含开场页、三问、2D 降级）

## 方法

- 标准：WCAG 2.1，对比度 = (L1 + 0.05) / (L2 + 0.05)，L 为相对亮度
- 前景色取自 `getComputedStyle().color`；**半透明背景逐层合成为不透明色**后再算，所以面板 `rgba(10,17,20,0.86)` 这类值不会算错
- 视口 1440×900，DPR 1，Edge 157 headless
- 判定：正文与常规字号要求 ≥ 4.5:1；≥ 7:1 记为 AAA

## 结论

- **两套主题、15 个采样点全部 ≥ 4.5:1**，没有不达标项
- 最低值是 **3D 版顶栏页码与开场提示 5.18:1**；2D 版把 `--mist` 压深后从 4.53 提到 5.32
- 3D 版最低值 5.18:1，主要来自辅助文字 `--mist`（`rgb(126,154,154)`）
