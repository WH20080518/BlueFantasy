## 2. 工作流

- **文案**：中文定稿 → 英文重写（不是直译）→ 母语/高年级审校 → 术语统一
- **3D**：Rhino blockout → 剖切/节点 → OBJ/FBX → Blender 减面/UV/AO → GLB → Three.js
- **前端**：骨架 → 单 beat 跑通 → 爆炸/漏水/补缝 → 多语种 → 性能 → 降级
- **交付**：演示脚本 → 录屏 → 作品说明 → AI 说明 → 打包自查

## 3. 分工建议（2–5 人）

| 角色 | 职责 |
|---|---|
| 队长/统筹 | 排期、评审标准对齐、材料汇总、对外沟通 |
| 内容/翻译 | 文章与史料、中文文案、英文重写、术语表、译注 |
| 3D/视觉 | 船体与节点建模、Rhino/Blender、材质与镜头 |
| 前端 | 页面架构、滚动引擎、Three.js、多语种、部署 |
| 记录/交付 | 过程记录、录屏、作品说明、AI 说明、打包 |

人少时合并：

- 队长兼前端
- 内容兼翻译
- 3D 兼视觉
- 录屏可由队长兼

**硬要求**：至少一人能审英文；至少一人能稳定产出 GLB。两者缺一，11-12 就要调整范围。

## 4. 关键路径

```
选题（已定）
  → 7 个 beat + 术语表（11-11）
  → 中英文案（11-12）
  → 船体 blockout（11-12）
  → 3D 剖切/节点（11-13 ~ 11-15）
  → 前端接入（11-14 ~ 11-16）
  → 录屏与材料（11-17 ~ 11-18）
```

**3D 是唯一可能拖垮排期的环节。** 11-15 还没有可用 GLB，就切 SVG 等距图，文案与交互不变。

## 5. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 3D 交付延期 | 页面空心 | 11-15 切 SVG 等距爆炸图，保留文案与漏水示意 |
| 英文翻译生硬 | 文化传播扣分 | 英文重写 + 审校 + 术语表，不逐字直译 |
| 术语出错 | 专业度扣分 | 术语表 + 来源 + 母语者复核，标注“待核” |
| 手机性能不足 | 评审打不开 | 低模、DPR 上限 2、关闭阴影、可关闭 3D |
| 历史表述过度 | 文化误读 | 用“常见做法”，附来源，不绝对化 |
| 范围膨胀 | 9 天做不完 | 只做 3 个资产、4 个交互，不加新功能 |
| 录屏讲不清 | 传播价值失分 | 先写 60–90 秒脚本，再录 |
