# 排期与分工

> 截止：2026-11-19 24:00。按倒排推进，留出至少 2 天缓冲。

## 1. 里程碑

| 日期 | 里程碑 | 产出 |
|---|---|---|
| 11-10 | 立项、仓库与文档 | 架构、规则、清单、候选方向 |
| 11-11 | 方向确定 | 选题、语种、3D 范围、分工 |
| 11-12 | 叙事定稿 | 5—7 个 beat、文案初稿、术语表 |
| 11-13 | 视觉定稿 | style bible、关键帧/参考图 |
| 11-14 | 骨架可跑 | 页面结构、滚动引擎、语言切换 |
| 11-15 | 内容填充 | 全部文案、图片/SVG、音频 |
| 11-16 | 3D/动效 | 场景接入、动效打磨 |
| 11-17 | 联调与部署 | 公网链接、手机适配、性能 |
| 11-18 | 录制与文档 | 演示录屏、作品说明、AI 说明 |
| 11-19 | 提交 | 压缩包、邮件、自查 |

## 2. 工作流

- 文案：中文定稿 → 英文翻译 → 人工审校 → 术语统一
- 视觉：参考图 → style bible → 关键场景 → 全页统一
- 开发：骨架 → 单 beat 跑通 → 复制到全部 beat → 动效 → 性能
- 交付：录屏脚本 → 录制 → 说明文档 → 打包

## 3. 分工建议（2—5 人）

| 角色 | 职责 |
|---|---|
| 队长/统筹 | 排期、评审标准对齐、材料汇总、对外沟通 |
| 内容/翻译 | 选题资料、中文文案、外文翻译与审校、术语表 |
| 视觉/动效 | style bible、图片/SVG/3D、动效节奏 |
| 前端 | 页面架构、滚动引擎、多语种、部署 |
| 记录/交付 | 过程记录、录屏、作品说明、AI 说明、打包自查 |

人少时合并：队长兼前端，内容兼翻译，视觉兼录屏。

## 4. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 方向迟迟不定 | 压缩开发时间 | 11-11 必须拍板，先用候选 A 做技术验证 |
| 翻译返工 | 文案与页面不同步 | 先定术语表，文案与代码分离 |
| 3D 性能不达标 | 手机卡顿/加载失败 | 3D 局部化，默认 DOM/SVG，可回退 |
| 素材版权不清 | 不能参赛 | 优先自制/AI 生成/明确授权素材，登记来源 |
| 链接评审期失效 | 材料不全 | 用稳定静态托管，提交前换设备实测 |
| 录屏讲不清交互 | 传播价值失分 | 先写 60 秒演示脚本，再录 |

## 5. 每周检查

- 仓库是否有可运行版本
- 公网链接是否可打开
- 多语种是否同步
- 材料清单是否缺项
- 是否有未登记的素材
