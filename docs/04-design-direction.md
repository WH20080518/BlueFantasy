## 1. 一句话

**把一艘中国古船拆开，看见榫、钉、捻缝与水密隔舱，也看见“榫卯”这个词如何穿过语言。**

英文：*Take a Chinese ship apart: tenons, nails, caulking, watertight compartments — and the word “mortise-and-tenon” as it crosses languages.*

## 2. 为什么是《榫合》

### 2.1 纠正一个流行误解

大众叙事里常说“中国古船不用一根钉”，把家具榫卯的浪漫想象套到船上。实际造船常见做法是：

- **榫卯**：榫头 + 卯眼，负责定位与连接
- **钉接**：铁钉/铜钉加固
- **捻缝**：桐油灰 + 麻丝填缝，保证水密
- **水密隔舱**：隔舱板把船体分成多个独立舱室

文章原词是 **“榫合钉接”**，不是“纯榫卯”。这个纠正本身就有研究深度，也直接对应评审里的“避免文化误读”。

### 2.2 三个“只有网页能做”的交互

- **拆开**：整船爆炸成零件，点击查看
- **漏水**：切换隔舱，观察船是否还能浮
- **补缝**：在船板接缝上选择榫卯/铁钉/捻缝，选错就渗水

### 2.3 翻译学院的主场

- 英文没有与“榫卯”完全对等的单词，通常只能写 `mortise-and-tenon joint`
- 构件术语、材料术语、制度术语都涉及“译什么、丢什么”
- 多语种不是贴标签，而是页面机制

### 2.4 与评分标准对应

| 评分维度 | 本方案的落点 |
|---|---|
| 创新性 25% | 用 3D 拆解 + 漏水实验讲结构，不是图文展板 |
| 文化传播 25% | 纠正“古船不用钉”的误读；术语多语种对照 |
| 专业表达 20% | 结构、文案、交互三层都围绕“连接” |
| 传播前景 15% | 60–90 秒可演示；链接可分享；手机可用 |
| 团队材料 15% | 文档、建模 brief、术语表、AI 说明齐全 |

## 3. 叙事结构（7 个 beat）

| # | Beat | 画面 / 交互 | 文案要点 | 事实来源 |
|---|---|---|---|---|
| 1 | 一句流行说法 | 整船剪影，外壳半透明，浮出一句“古船不用一根钉？” | 先立误解，不急着纠正 | 大众叙事常见说法 |
| 2 | 榫头与卯眼 | 镜头推近节点，零件爆炸；点击术语 | 木头如何互相咬住 | 泉州湾宋船、南海I号 |
| 3 | 钉与缝 | 铁钉、木钉、桐油灰、麻丝分层出现 | 榫卯之外，还有钉与缝 | 造船史、沉船考古 |
| 4 | 水密隔舱 | 剖切船体，露出 3 道隔舱板 | 一艘船被分成多个“房间” | 泉州湾宋船、华光礁I号 |
| 5 | 漏水实验 | 一个舱进水，船仍浮；关闭隔舱则下沉 | 为什么一舱进水不沉 | 水密隔舱原理 |
| 6 | 术语出海 | 构件旁弹出中/英/日/韩词条 | “榫卯”不可直译，翻译也是连接 | 术语表、译注 |
| 7 | 收束 | 回到整船，出现沉船/造船技艺来源 | 从古船到今天 | 博物馆、论文、非遗 |

**总滚动长度**：6–8 屏；beat 1 与 beat 5 停留更长。

## 4. 交互设计

### 4.1 页面结构

- 左侧/上方：固定文案区（eyebrow、标题、正文）
- 右侧/中央：sticky 3D stage（`position: sticky; top: 0; height: 100vh`）
- 移动端：3D stage 在上，文案在下；不做左右分栏

### 4.2 四个核心交互

**A. 拆开一艘船**
- 滚动到 beat 2，船体爆炸
- 点击零件：高亮 + 名称 + 一句话解释
- 再次点击：复位
- 键盘：零件列表可 Tab 切换

**B. 漏水实验**
- beat 5 出现开关：「有水密隔舱 / 无隔舱」
- 有水密隔舱：单舱进水，船轻微倾斜后稳定
- 无隔舱：水面上升，船体下沉
- 可重复播放；录屏时作为高潮

**C. 补一道缝**
- beat 3 或独立小节
- 放大船板接缝，用户按顺序选择「榫卯 → 铁钉 → 捻缝」
- 选错：渗水粒子 + 提示；选对：缝闭合
- 移动端用点击，不做拖拽

**D. 术语出海**
- hover/点击任一构件，弹出词条
- 中英为主，日/韩为待核；标注“直译 / 意译 / 不可译”
- 语言切换不重置 3D 状态与滚动位置

### 4.3 状态与降级

| 状态 | 行为 |
|---|---|
| 无 WebGL | 显示 SVG 等距爆炸图 + 静态节点图，文案完整可读 |
| 低性能设备 | 关闭阴影、降低 DPR、减少零件动画 |
| `prefers-reduced-motion` | 直接切换爆炸/漏水状态，不做位移动画 |
| 3D 加载失败 | 保留文案与 SVG，控制台报错，不白屏 |

## 5. 视觉方向（style bible）

### 5.1 色彩

| 名称 | 色值 | 用途 |
|---|---|---|
| 船木 | `#3A2A20` | 主背景、船体深色 |
| 桐油 | `#C08A4A` | 木构件高光、强调 |
| 铁灰 | `#4B5154` | 钉、工具、次级文字 |
| 灰白 | `#E9E3D6` | 主文字、剖切面 |
| 海雾 | `#7E9A9A` | 辅助信息、水面 |
| 朱砂 | `#B5432F` | 唯一强调色：错误、渗水、关键按钮 |

**规则**：一套主色 + 一个强调色；不加大面积渐变；不用紫蓝科技色。

### 5.2 字体

- 中文标题：`Songti SC / Noto Serif CJK SC / Source Han Serif SC`
- 中文正文：`PingFang SC / Noto Sans CJK SC`
- 英文标题：`Iowan Old Style / Palatino / Georgia`
- 英文正文：同上或系统 serif
- 数字/尺寸：`JetBrains Mono / SFMono-Regular / Consolas`

### 5.3 材质与图形

- 木、铁、灰、纸四种质感
- 细线分隔，不用圆角卡片堆叠
- 剖切面用灰白 + 细线，不用发光边
- 图标用线性 SVG，不用 emoji

### 5.4 动效语法

- 主运动：**结构展开**（零件沿装配方向分离）
- 次运动：镜头推近、轻微视差
- 时长：600–900ms；错峰 40–60ms
- 缓动：`cubic-bezier(.22, 1, .36, 1)`
- 不做无意义的淡入、漂浮、循环旋转

## 6. 多语种策略

### 6.1 语种

- 中文（源语言）
- English（必做）
- 第三语种：11-12 由团队按审校能力定（日/韩/俄/法选一）

### 6.2 术语与译注

- 以 [`07-modeling-brief.md`](07-modeling-brief.md) 的术语表为基础
- 每个核心构件至少三条信息：中文名、英文名、一句解释
- 标注三类情况：
  - 可直接对应：keel / bulkhead
  - 需要解释：mortise-and-tenon joint
  - 不可直译：榫卯的“合”、捻缝的“缝”
- 日/韩术语必须母语者复核后再上线

### 6.3 文案原则

- 先解释，再抒情
- 不把中国海洋文化写成“神秘东方”
- 不用“自古以来”代替具体证据
- 英文不是中文的逐字直译，允许重写句子

## 7. 技术范围与预算

- 3D 资产：剖切船体 + 榫卯节点 + 船壳板接缝
- 总三角面 ≤ 35,000
- GLB ≤ 5 MB（Draco）
- 纹理 ≤ 2 张 1024，或不用贴图
- Draw call ≤ 20
- 桌面 60fps，移动端 ≥ 30fps
- 首屏不加载 3D；进入 beat 2 前预加载
- Three.js 独立 chunk，`import()` 动态加载

## 8. 事实边界

- 不同沉船的榫卯、钉接、捻缝做法不完全相同，文案用“常见做法”，不用“所有古船都这样”
- 不声称“完全不用钉”
- 不伪造精确考古尺寸
- 不使用博物馆或他人模型，除非有明确授权
- 参考：泉州湾宋代海船、南海I号、华光礁I号、《天工开物》、中国造船史论文

## 9. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 3D 交付延期 | 页面空心 | 11-15 未交则切 SVG 等距图，文案不变 |
| 术语翻译出错 | 文化传播扣分 | 术语表 + 母语者复核 + 译注 |
| 手机性能不足 | 评审打不开 | 3D 局部、低模、DPR 上限 2、可关闭 3D |
| 历史表述过度 | 文化误读 | 用“常见做法”，附来源，不绝对化 |
| 范围膨胀 | 9 天做不完 | 只做 3 个资产、4 个交互，不加新功能 |
