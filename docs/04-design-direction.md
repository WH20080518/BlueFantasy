## 1. 评审倒推

评分中权重最高的两项：

- 创新性与前瞻性 25%
- 文化传播价值 25%（含多语种译介准确度、跨文化适配）

因此选题必须同时满足：

1. 有明确的中华海洋文化内核，不是泛泛的“大海很美”
2. 有可被外语受众理解的切入点，不需要大量前置知识
3. 有“只有网页能做”的交互，不是把文章排版成网页
4. 有可核查的事实与素材来源，避免文化误读

## 2. 候选 A：岚山渔民号子

**一句话**：把“一领众和”的劳动号子变成可参与的声音叙事。

**叙事结构（草案）**

1. 起锚：黎明、雾、船出港
2. 号子是什么：领号与和号的关系
3. 劳动现场：摇橹、拉网、起锚，不同号子对应不同动作
4. 声音的消失：机械化、年轻人离海
5. 活态传承：谁还在唱，怎么学
6. 跨文化对照：水手号子（sea shanty）与渔民号子
7. 邀请：听一段、跟一句

**交互**

- 点击/长按触发号子段落，页面以波形与文字同步呈现“领—和”
- 滚动到不同劳动场景，背景节奏与文案变化
- 中英对照展示“号子不可直译”的部分，用注释解释劳动语境
- 可选：用户跟读录音（本地处理，不上传）

**视觉方向**

- 海雾灰、盐白、旧木褐、信号橙
- 字体：中文宋体/黑体对比，英文 condensed sans
- 材质：湿润的木、绳索、雾

**优势**：交互独特性最强；声音是天然的记忆点；非遗属性明确
**风险**：音频版权与录制质量；海外受众对“号子”无概念，需要更多解释
**多语种难点**：拟声词、劳动口令不可直译，需要“译+注”策略

## 3. 候选 B：荣成海草房

**一句话**：用一栋房子讲清“人—海—气候—渔业”的关系。

**叙事结构（草案）**

1. 屋顶：海草为什么能盖房
2. 材料：大叶藻、潮间带、潮汐
3. 建造：苫匠、坡度、排水
4. 生活：冬暖夏凉、渔村聚落
5. 变化：海草减少、旅游与保护
6. 跨文化对照：爱尔兰 thatch、日本茅葺
7. 邀请：看一眼屋顶的厚度

**交互**

- 滚动推进“从海草到屋顶”的材料转化
- 可拖动的剖面图，展示墙体、屋顶、排水
- 点击热点查看构件名称与多语种注释
- 时间轴对比“过去—现在”

**视觉方向**

- 海草灰褐、石灰白、深海蓝、苔绿
- 字体：中文人文宋体，英文 serif
- 材质：粗粝、手工、时间感

**优势**：视觉辨识度最高；生态与建筑两条线都硬；图片/3D 都容易出效果
**风险**：需要高质量图像或模型；容易做成“建筑科普”
**多语种难点**：建筑术语与地方名，需要术语表

## 4. 候选 C：登州古港与海上丝路

**一句话**：以一座港口为轴，讲货物、船与人的跨海流动。

**叙事结构（草案）**

1. 港口：登州的位置与季风
2. 船：不同船型与航线
3. 货：丝绸、瓷器、海产、香料
4. 人：使节、商人、僧人、渔民
5. 交流：语言、信仰、技术的交换
6. 对照：泉州、长崎、马六甲
7. 邀请：在地图上选一条航线

**交互**

- 可旋转/缩放的古地图，点击港口展开卡片
- 航线动画与货物清单联动
- 多语种地名与古称对照
- 时间轴切换不同朝代

**视觉方向**

- 海图米、墨黑、朱砂、靛青
- 字体：中文刻本宋体，英文 old style serif
- 材质：纸、墨、海图

**优势**：历史纵深强；跨文化对照自然；资料相对多
**风险**：容易变成资料堆砌；地图交互在手机上难做好；创新性容易同质化
**多语种难点**：古地名、官职、货物名，译法需要统一

## 6. 建议

- 若团队有声音/音乐能力：选 **A**
- 若团队有视觉/建模能力：选 **B**
- 若团队强在翻译与史料：选 **C**，但必须设计一个强交互，避免资料堆砌
