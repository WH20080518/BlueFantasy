# 交付清单与命名规范

> 提交前逐项勾选。材料不全会进入补交流程，命名不规范会被要求补正。

## 1. 提交时间

- [ ] 2026-11-19 24:00 前发送
- [ ] 报名表、作品、创作说明、AI 创作说明一并提交

## 2. B 赛道交互类材料

- [ ] 完整演示录屏（建议 1—3 分钟，1080P，MP4/MOV，H.264）
- [ ] 可访问的测试链接（评审期内保持可用）
- [ ] 源代码（完整仓库或压缩包）
- [ ] 作品说明 200—400 字（Word）
- [ ] AI 创作说明 300—500 字（Word，使用 AI 时必交）

## 3. 文件命名

统一格式：`赛道＋队长姓名＋作品名称`

示例：

- 作品：`B赛道＋张三＋潮生`
- 作品说明：`B赛道＋张三＋作品说明`
- AI 创作说明：`B赛道＋张三＋AI创作说明`
- 演示录屏：`B赛道＋张三＋演示录屏`

## 4. 压缩包与邮件

- 压缩包命名：`蓝色创想+赛道+团队名称`
- 邮件主题：与压缩包一致
- 一封邮件只对应一个作品
- 同一团队多个作品：分别打包、分别发送
- 邮件正文建议附：团队名称、队长联系方式、作品链接

## 5. AI 创作说明必须覆盖的四点

1. 所用 AI 工具的名称与类型
2. AI 参与的具体环节（素材生成、翻译初稿、画面渲染、配音合成等）
3. 团队人工完成与修改的内容
4. 团队对 AI 生成内容的核验方式

> 说明与实际作品明显不符，按材料不全处理，不进入评审。

## 6. 多语种检查

- [ ] 至少中英双语，建议增加第三语种
- [ ] 译文经人工审校，不是机翻直出
- [ ] 文化专名有统一译法（如地名、非遗名称、民俗术语）
- [ ] 外语版不是中文版的逐字直译，语序与表达符合目标语言习惯
- [ ] 页面语言切换不丢失当前叙事位置

## 7. 素材与版权

- [ ] 图片、音频、视频、字体、3D 模型均有来源记录
- [ ] 使用第三方素材时确认授权范围
- [ ] AI 生成素材在 AI 说明中披露
- [ ] 仓库中保留 `docs/assets-credits.md`（后续创建）

## 8. 技术自检

- [ ] 公网链接可打开，无登录墙
- [ ] 手机端（375px）无横向滚动
- [ ] 桌面端（1440px）布局正常
- [ ] 首屏加载可接受，3D 资源不阻塞文字
- [ ] GLB ≤ 5 MB，总三角面 ≤ 35,000，draw call ≤ 20
- [ ] 3D 节点名与 `ship-parts.json` 一致，无缺失节点
- [ ] 无 WebGL / 加载失败时显示 SVG 等距图，文案完整
- [ ] 漏水实验、补缝、爆炸动画可重复播放
- [ ] 键盘可操作，焦点可见
- [ ] `prefers-reduced-motion` 生效
- [ ] 控制台无报错
- [ ] 录屏覆盖完整交互路径，不剪切关键动作

## 9. 仓库自检

- [ ] `.gitignore` 生效，`node_modules/`、`dist/` 未提交
- [ ] 未提交 `.env`、密钥、token
- [ ] 大模型文件使用 Git LFS 或压到 10 MB 内
- [ ] README 能让他人独立跑起来
- [ ] 提交记录清晰，无巨型二进制历史
