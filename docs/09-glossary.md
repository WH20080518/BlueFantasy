# 术语表与译法（Glossary）

> 版本：v1 · 2026-11-11
> 用途：beat 6 的弹窗词条、3D 零件标注、英文文案统一用词
> 原则：**先标译法类型，再给译名。** 能直译的直译，不能直译的写解释，不要硬造词。

## 0. 译法标记

| 标记 | 含义 | 页面上怎么呈现 |
|---|---|---|
| 直译 | 目标语有对应概念，可直接对译 | 只给译名 |
| 解释译 | 无单词对应，用短语解释 | 译名 + 一句解释 |
| 音译 | 只能音译 + 说明 | 拼音 + 斜体说明 |
| 待核 | 尚未确认权威译法 | 不展示，或标注「待核」 |

**统一口径**：英文正文用 `mortise-and-tenon` 作连字符形容词，名词短语写 `mortise-and-tenon joint`；不写 `mortise and tenon joint`（无连字符）在标题里，避免断行出错。

### 0.1 英文用词对照（全文共用，改文案前先看这张表）

| 中文 | 唯一写法 | 不要写 |
|---|---|---|
| 榫卯（作定语） | `mortise-and-tenon` | `mortise and tenon`（无连字符） |
| 榫卯（名词） | `mortise-and-tenon joint` | `tenon joint` 单独指代整个词 |
| 榫头 / 卯眼 | `tenon` / `mortise` | `tenon joint` 指榫头 |
| 隔舱板（水密语境） | `watertight bulkhead` | `partition` |
| 水密隔舱（讲制度/结构） | `watertight bulkhead system` | `watertight cabin` |
| 舱（装货） | `hold` | `room` |
| 舱（讲分隔） | `compartment` | 与 `hold` 同段混用 |
| 木钉 | `treenail`（首次 `treenail (wooden peg)`） | `wooden nail` |
| 桐油灰 | `tung-oil putty` | `Chinese putty` |
| 捻缝 | 动 `to caulk`，名 `caulking` | 单用 `seal` 代替 |
| 船壳板（整层） | `hull planking` | `hull planks` 指整层 |
| 残长 | `surviving length 24.2 m` | 裸写 `24.2 m` |

### 0.2 英文文体约定

- 主动句、短句；句首不用 `So,` / `Interestingly,` / `Importantly` 这类副词开场。
- 不写 `ancient Chinese wisdom`、`mysterious East`、`timeless` 一类营销语。
- 不写 `the world's first`、`unique to China`、`leading the West by centuries`。日本与欧洲都有同类节点，只是形制不同。
- 术语首次出现给全称，之后可用简写，但简写必须先在上面这张表登记。
- 标题不用句号；正文一句话在 24 词以内的优先。

## 4. 第三语种：决定不启用（2026-11-12）

**结论：本期只做中文 + English，日/韩不启用。**

理由：

- 日语、韩语词条目前没有任何可引用的专业辞书或博物馆展陈作依据，`10-fact-check.md` 的原则是「宁可少说一句，不要多说一句」。
- 术语错译在「文化传播」25% 这一项上是直接扣分，而多一个语种带来的加分很有限。
- 中英文案本身还在打磨期，拆人力去开第三语种会拖慢主线。

页面结构不受影响：UI 与 `glossary.js` 都是数据驱动的，日后启用只需加字段与语种数组，不动组件。

如果后续要改这个决定，三条必须同时满足：有一手可引用依据、有母语者复核、页面标注语种来源。

候选词（仅备查，**不可直接上线**）：榫（ほぞ）、継手（つぎて）、水密隔壁（すいみつかくへき）。

## 5. 写作禁忌

- 不写「中国古船不用一根钉」作为结论句（只能作为被纠正的流行说法）
- 不写「世界上最早的…」除非有具体来源
- 不把家具榫卯的表述直接搬到船上
- 不把 `mortise-and-tenon` 当成 榫卯 的唯一正确译法来宣称；写作「最接近的英文表达」
- 数字（隔舱数、年代、船长）凡未经核对，一律改为定性描述
