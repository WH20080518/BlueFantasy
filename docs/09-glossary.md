# 术语表与译法（Glossary）

> 版本：v1 · 2026-11-11
> 用途：beat 6 的弹窗词条、3D 零件标注、英文文案统一用词
> 原则：**先标译法类型，再给译名。** 能直译的直译，不能直译的写解释，不要硬造词。

## 0. 译法标记

| 标记 | 含义 | 页面上怎么呈现 |
|---|---|---|
| 直译 | 目标语有对应概念，可直接对译 | 只给译名 |
| 解释译 | 无单词对应，用短语解释 | 译名 + 一句解释 |
| 音译 | 只能音译 + 说明 | 拼音 + 斜体说明 |
| 待核 | 尚未确认权威译法 | 不展示，或标注「待核」 |

**统一口径**：英文正文用 `mortise-and-tenon` 作连字符形容词，名词短语写 `mortise-and-tenon joint`；不写 `mortise and tenon joint`（无连字符）在标题里，避免断行出错。

## 3. 抽象与叙事词

| 中文 | 英文 | 类型 | 说明 / 备注 |
|---|---|---|---|
| 连接 | joint / connection | 直译 | 讲结构用 `joint`，讲关系用 `connection` |
| 咬住 | hold | 解释译 | 「木头咬住木头」→ `wood holds wood`，不译 `bite` |
| 出海 | put to sea | 直译 | |
| 误读 | misreading | 直译 | |
| 传播 | circulation | 解释译 | 文化传播语境用 `cultural circulation`，不用 `spread` |

## 4. 第三语种（待核，11-12 决定）

日语、韩语词条目前**没有**可靠来源，暂定不启用。若要启用，需满足：

- 有至少一条可引用的专业辞书或博物馆展陈作为依据
- 由人或可信模型复核，不得由未核对的机器翻译直接上线
- 页面上标注语种来源

候选词（仅备查，**不可直接上线**）：榫（ほぞ）、継手（つぎて）、水密隔壁（すいみつかくへき）。

## 5. 写作禁忌

- 不写「中国古船不用一根钉」作为结论句（只能作为被纠正的流行说法）
- 不写「世界上最早的…」除非有具体来源
- 不把家具榫卯的表述直接搬到船上
- 不把 `mortise-and-tenon` 当成 榫卯 的唯一正确译法来宣称；写作「最接近的英文表达」
- 数字（隔舱数、年代、船长）凡未经核对，一律改为定性描述
