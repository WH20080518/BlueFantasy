A multilingual, interactive web story about China’s maritime culture.

项目简介 · About

本项目参加山东大学翻译学院「蓝色创想·以语为桥」跨文化传播创新实践大赛 B 赛道（蓝色数字传播），以交互式网页讲述中国海洋故事。

作品以中文为源语言，提供英文版本，尝试用多语种搭建跨文化理解的桥梁。选题、交互形式与视觉方向仍在团队讨论中，内容将随后续定稿更新。

An interactive web project for the BlueFantasy cross-cultural communication competition, telling China’s maritime story across languages.
